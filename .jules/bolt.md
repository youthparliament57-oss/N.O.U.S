## 2026-03-30 - Vector Search Inner Loop Scaling & Type Accumulation
**Learning:** In cosine similarity calculations, positive scaling factors (such as INT8 quantization scale) cancel out mathematically because $cos(A, S \cdot B) = cos(A, B)$. Quantizing the query vector on the fly or multiplying by the scale factor within inner loops introduces unnecessary float-to-int coercions, float multiplications, and bit decoding operations per vector element. Additionally, using `Double` accumulators for `FloatArray` vector math on Android ART introduces implicit scalar type conversions that hinder SIMD/autovectorization.
**Action:** Always compute cosine similarity directly using unquantized query `Float` values against raw quantized `Byte` values, accumulating in `Float`/`Long` primitives and relying on norm division at the end.
